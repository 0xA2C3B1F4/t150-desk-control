Maintenance steps and image requirements

With controller power off, disconnect the motor cable. Keep the ESP32 powered and UART connected throughout maintenance.

  1. Enter maintenance and select Read controller firmware. Turn only the controller off and on when the current step asks for it.
  2. Download the backup and confirm that it is saved on your computer. Prepare DT02 or CL01, or select a saved application file.
  3. Confirm and arm installation. Restart the controller when instructed, then leave power connected throughout writing.
  4. Select Verify by full readback after writing. Restart the controller again when instructed. Only a complete readback verifies the installation.
  5. Finish maintenance, then restart the controller for normal operation. Reconnect the motor only with controller power off.

Installation erases application flash. A failed transfer may require restoring the original file. Only exact supported 55,296-byte original, DT02 or CL01 application files can be installed. Unknown versions can be saved for research.

Files in this page are temporary. The computer download is your persistent backup.
